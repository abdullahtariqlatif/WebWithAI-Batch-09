# Your 2–3 Week Compression Strategy

Because you're already a senior-ish Rails developer, **don't spend equal time on everything**.

I'd divide your catch-up roughly like this:

```text
                 PRIORITY
JavaScript          ██████████
React               ██████████
Express/MERN        ██████████
Mongo/Mongoose      █████████
Rails → MERN        ██████████
Testing             ███████
Docker              ███████
n8n                 █████████
Python              ████
Streamlit/Pydantic  ███
HTML/CSS            ██
Bootstrap           ██
Tailwind            ███
```

Your biggest gap isn't likely **“what is MVC?”**

You already know MVC.

Your gap is:

> **“How does this ecosystem implement the things I already know how to architect in Rails?”**

That's a very different learning problem.

So whenever you learn something, immediately translate it:

```text
Rails                         MERN

ActiveRecord            →     Mongoose
Controller              →     Express Controller
Service Object          →     Service
Routes                  →     Express Router
before_action           →     Middleware
Devise                  →     JWT/Auth library
Pundit                  →     Authorization layer
ActiveJob               →     BullMQ
Sidekiq                 →     Queue/Worker
ActionMailer            →     Nodemailer
ActiveStorage           →     Multer + S3
ActionCable              →     Socket.IO
RSpec                   →     Jest/Vitest
FactoryBot              →     Test factories
Rails.env               →     NODE_ENV
credentials/config      →     .env/config
```

That's the **core mental model** I would use throughout the entire catch-up.
