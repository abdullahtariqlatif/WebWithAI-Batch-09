# Full Course Roadmap

A structured roadmap for becoming a full-stack web developer, covering
HTML, CSS, JavaScript, React, TypeScript, backend development, databases, testing,
deployment, Python, automation, AI, and production application development.

## How to Use This Roadmap

* Each phase is one file. Work through its numbered sections in order (4.1, 4.2, …), then do its **Practice** section.
* A checkbox is one topic to learn. Related terms share a line, so tick it once you understand all of them.
* Every topic lives in exactly **one** phase. When another phase needs it, it says so with an arrow, e.g. "Sessions vs tokens → Phase 8.5", instead of repeating the list.
* Diagrams, guidance, and selection criteria are plain text, not checkboxes.
* Understand topics and practice them in projects. Don't tick them off just because you watched or read about them.
* Rails developers: start with [8.1 Rails → Node Mental Model](./phase-08-backend-architecture-auth-api.md#81-rails--node-mental-model) and translate as you go.
