## How to Use This Roadmap

Each phase has its own Markdown file containing the detailed
topics, concepts, and practice work for that phase.

Work through the phases in order, checking items off as they are
completed.

The roadmap is intended to be both a course outline and a personal
learning roadmap. Topics should be understood conceptually and
reinforced through practice and projects rather than simply checked
off after being watched or read.
