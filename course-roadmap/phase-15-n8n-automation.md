## Practice

Build these in order; each one is harder than the last.

* [ ] Webhook → validate data → Google Sheet
* [ ] Schedule → fetch API → transform → send email
* [ ] Form → webhook → database → email → Slack
* [ ] Incoming email → process → AI/API → Google Docs → notification
* [ ] Webhook → API → AI → database → email → Slack → logging
