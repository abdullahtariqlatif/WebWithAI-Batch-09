# PHASE 17 — Final "Can I Actually Do This?" Checklist

Before calling the course complete, you should be able to answer **yes** to these.

## Frontend

* [ ] I can create a React project from scratch
* [ ] I understand JSX, props & state
* [ ] I can build forms & use hooks, effects & Context
* [ ] I can use Redux Toolkit & configure React Router
* [ ] I can integrate APIs & structure a large React application

## Backend

* [ ] I can create an Express server from scratch & understand middleware
* [ ] I can create REST APIs & structure an MVC application with services
* [ ] I can implement authentication & authorization
* [ ] I can validate requests & handle errors
* [ ] I can upload files, send emails & create background jobs
* [ ] I can build WebSocket features

## Database

* [ ] I can design MongoDB schemas & use Mongoose
* [ ] I understand relationships & indexes
* [ ] I can paginate & query efficiently
* [ ] I can model the same data in PostgreSQL with Prisma

## Testing

* [ ] I can write unit & API tests
* [ ] I can mock dependencies & create test data
* [ ] I can test authentication & authorization
* [ ] I can test React components

## DevOps

* [ ] I can write a Dockerfile & Docker Compose file
* [ ] I can run the full stack locally
* [ ] I understand environment variables
* [ ] I can deploy a frontend, a backend & a production database
* [ ] I can debug deployment problems

## TypeScript

* [ ] I can write typed Express & React code

## Automation

* [ ] I can build n8n workflows with webhooks, schedules & API calls
* [ ] I can authenticate APIs, transform data & use JavaScript inside workflows
* [ ] I can connect SaaS services & handle failures

## Python

* [ ] I understand Python syntax, scripts & virtual environments
* [ ] I can use Pydantic
* [ ] I can create a Streamlit application connected to APIs

## AI

* [ ] I can add an LLM-powered feature to a web application
* [ ] I can build & deploy a chatbot
